# GalleryPlanner

GalleryPlanner is a browser-based, local-first tool for planning gallery walls. It helps you arrange real frame sizes, preview photos, and create drill-ready hanging guides.

GalleryPlanner is a closed-source, private project and its application code is not publicly available.
